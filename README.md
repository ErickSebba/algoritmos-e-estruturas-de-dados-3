# Algoritmos e Estrutura de Dados 3 (AED3)

Algoritmos e trabalhos em C da disciplina de AED3.

## Estrutura
- `Arvores/`: árvores AVL, B, binária e rubro-negra.
- `Algoritmos/`: Dijkstra.
- `Pastas.c/`: trabalho (`Main.c`, `SepararStrings.c` e arquivos de cada integrante).
- `TrabalhoAED3/`: outra versão do trabalho (`Arquivo.c` e arquivos de cada integrante).

Compilar com `gcc arquivo.c -o programa`.
